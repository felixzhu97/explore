# Executive（CEO / 业务高管）

**不是** Scrum 三人组角色，而是 **企业战略干系人**（可与 Sponsor 兼任）：定公司级方向与资源边界，通过 Scrum Team 的 Product Owner 对齐进交付。

Prefer the specific child skill when the task is clear.

## Accountability (vs Scrum Team)

| Role | Owns |
|------|------|
| **Executive (CEO / 高管)** | 公司愿景、战略主题、投什么/不投什么、商业模式与品牌方向 |
| Product Owner | 团队 Backlog、验收、迭代价值最大化（执行层） |
| Scrum Master | 流程与持续改进 |
| Developers | 增量交付（含质量） |

## Skills in this role

- [`enterprise-strategy`](./enterprise-strategy/) — 愿景、战略主题、投资组合、公司级 OKR
- [`business-model-generator`](./business-model-generator/) — 商业画布与盈利模型
- [`apple-marketing`](./apple-marketing/) — 品牌定位与增长叙事（公司/产品商业化）
