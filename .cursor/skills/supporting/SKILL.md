# Supporting（支撑 / 赋能）

规模化或专长分工里常见，**不是** Scrum 规定的三人职责。可嵌入 Developers，或作为共享服务赋能多个团队。

| 角色 | 目录 | 职责 |
|------|------|------|
| **UX Designer** | [`ux-designer/`](./ux-designer/) | 体验与界面 |
| **Architect** | [`architect/`](./architect/) | 架构约束与评审 |
| **DevOps** | [`devops/`](./devops/) | 交付平台与基础设施 |
| **Researcher** | [`researcher/`](./researcher/) | 研究与实验标准 |

在纯 Scrum 小团队中，上述能力常由 **Developers** 交叉覆盖。
