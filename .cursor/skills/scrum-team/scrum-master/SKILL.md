# Scrum Master

Scrum Team 中负责 **效能与流程** 的人（教练 / 促进者，不是项目经理替团队做决定）。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| **Scrum Master** | Process, collaboration, impediments, continuous improvement |
| Executive（干系人） | Company vision, investment portfolio |
| Product Owner | Backlog priority and acceptance inside strategy themes |
| Developers | Building the increment (including quality) |

## Skills in this role

- [`process-improvement`](./process-improvement/) — retros, Kaizen, flow metrics, impediment handling
