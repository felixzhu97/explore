# Customer（客户）

**买单或签约** 的一方（B2B 关键客户、采购方、付费订阅主体）。不一定等于 User。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| **Customer** | 商业诉求、合同/SLA、客户成功标准 |
| User | 实际使用体验与任务完成 |
| Product Owner | 把客户诉求与用户需求平衡进 Backlog |

## Skills in this role

- [`customer-outcomes`](./customer-outcomes/) — 客户成功标准、反馈与商业约束
