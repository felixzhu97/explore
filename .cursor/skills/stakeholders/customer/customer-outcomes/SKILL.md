# Customer Outcomes

## Distinguish

| | Customer | User |
|--|----------|------|
| Question | 为什么付钱 / 续约？ | 日常怎么完成任务？ |
| Artifacts | 合同、SLA、ROI、采购标准 | 场景、旅程、可用性 |

## Capture template

```text
Customer:
Job to be done (commercial):
Success metric:
Must-have constraints (legal/SLA):
Nice-to-have:
Competitive alternative if we fail:
```

## Handoff to PO

- 客户结果 → 候选 Epic / 主题
- SLA → 非功能需求 / DoD
- 不直接变成未排序的「老板需求清单」
