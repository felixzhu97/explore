# Subject Matter Expert（领域专家）

提供 **领域真相** 的干系人：规则、术语、例外、历史坑。不拥有优先级。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| **SME** | 领域正确性、术语、业务规则细节 |
| Product Owner | 是否做、何时做 |
| Developers | 如何实现并保持模型诚实 |
| Compliance | 法定/审计硬约束（可与 SME 协作） |

## Skills in this role

- [`domain-expertise`](./domain-expertise/) — 规则、术语表、领域澄清
