# Compliance（合规）

法律、监管、安全、审计类干系人。输出的是 **硬约束**，通常进入 DoD / 非功能需求。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| **Compliance** | 红线、证据要求、审计可追溯性 |
| Product Owner | 在满足红线前提下排序价值 |
| Developers | 实现控制措施并保留证据 |
| SME | 可解释业务如何落地合规 |
