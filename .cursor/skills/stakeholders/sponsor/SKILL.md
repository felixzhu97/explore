# Sponsor（赞助人）

为某产品 / 项目提供 **授权与资源** 的干系人：能说「做 / 停 / 加钱」。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| **Sponsor** | 立项理由、预算、成功定义、关键升级 |
| Executive | 公司级组合与战略主题（可兼任 Sponsor） |
| Product Owner | Backlog 与迭代价值 |
| Scrum Master | 协助清除组织障碍并升级到 Sponsor |

## Skills in this role

- [`sponsorship`](./sponsorship/) — charter、预算、决策与升级路径
