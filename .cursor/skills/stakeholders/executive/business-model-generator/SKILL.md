# 商业与盈利模型生成

## 分析框架

使用以下框架进行全面分析：

1. **商业模式画布 (Business Model Canvas)** - 9大核心要素
2. **收入模型** - 多元收入流设计
3. **成本结构** - 固定/可变成本分析
4. **单位经济学** - CAC、LTV、GMV 测算

## 分析步骤

### 第一步：理解项目

分析项目现有代码和文档，识别：
- 核心产品/服务是什么
- 目标用户群体
- 现有功能模块
- 技术栈和资源投入

### 第二步：商业模式画布

输出以下9个核心要素：

| 要素 | 说明 |
|------|------|
| 价值主张 | 解决什么痛点 |
| 客户细分 | 谁是你的目标用户 |
| 渠道触达 | 如何获取用户 |
| 客户关系 | 如何维护用户 |
| 收入来源 | 如何赚钱 |
| 核心资源 | 需要什么关键资产 |
| 关键业务 | 必须做什么 |
| 关键合作 | 需要谁帮助 |
| 成本结构 | 需要花多少钱 |

### 第三步：收入模型设计

分析可行的收入模式：

| 收入模式 | 适用场景 |
|----------|----------|
| 订阅制 | 会员特权、功能解锁 |
| 交易抽成 | 平台交易手续费 |
| 广告变现 | 流量变现 |
| 增值服务 | 高级功能单独收费 |
| 授权费 | API/SDK 授权 |
| 增值商品 | 虚拟物品、表情包 |

### 第四步：单位经济学

计算关键指标：
- **CAC** (Customer Acquisition Cost) - 用户获取成本
- **LTV** (Lifetime Value) - 用户生命周期价值
- **LTV/CAC 比率** - 健康指标 > 3
- **月活用户 (MAU)** - 增长目标
- **付费转化率** - 变现效率

### 第五步：成本结构

分析项目成本：
- 开发成本（人力、技术）
- 运营成本（服务器、带宽）
- 营销成本（推广、广告）
- 合规成本（资质、许可）

## 输出格式

```markdown
# [项目名称] 商业与盈利模型

## 一、商业模式画布
[完整的9要素分析]

## 二、收入模型
[多元收入流设计和优先级]

## 三、单位经济学
[CAC/LTV/转化率等关键指标]

## 四、成本结构
[固定成本/可变成本分解]

## 五、盈利路径
[短期/中期/长期盈利策略]

## 六、风险与机遇
[市场风险、竞争风险、机遇分析]

## 七、财务预测（可选）
[基于合理假设的未来3-5年财务预测]
```

## 商业分析 Prompt 模板

当分析项目时，使用以下分析框架：

```
分析 [项目名称] 的商业模式：
1. 识别核心功能和用户价值
2. 确定目标市场和市场规模
3. 设计可行的收入来源
4. 评估技术和运营成本
5. 计算单位经济学指标
6. 制定盈利策略和时间表
```

## 注意事项

- 使用行业标准术语和数据格式
- 区分事实（现有信息）vs 推算（基于假设）
- 保持保守和乐观两种财务预测
- 引用相关行业数据和竞品对比
- 提出可落地的执行建议
