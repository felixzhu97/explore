# Product Owner

Scrum Team 中对 **产品 Backlog 与交付价值** 负责的人。  
公司级战略见 [`../executive/`](../executive/)。

Prefer the specific child skill when the task is clear.

## Accountability

| Role | Owns |
|------|------|
| Executive（干系人） | 愿景、战略主题、投资组合 |
| **Product Owner** | 主题之内的 Backlog、优先级、验收 |
| Scrum Master | 流程改进 |
| Developers | 增量交付（含质量） |

## Skills in this role

- [`backlog-value`](./backlog-value/) — 用户故事、优先级、验收与迭代价值
- [`public-docs-backlog`](./public-docs-backlog/) — meta-repo sync / C4 建票
- Jira 建票 / Epic 归属（先搜/建 Epic 再挂 Story·Task）：[`../developers/jira-delivery/`](../developers/jira-delivery/)
