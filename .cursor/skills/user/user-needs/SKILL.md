# User Needs

## When to use

- 用户访谈 / 可用性测试
- Sprint Review 收集使用者反馈
- 把「我觉得」变成可观察的任务结果

## Lightweight artifacts

```text
User segment:
Job / scenario:
Current workaround:
Desired outcome:
Friction (steps, time, errors):
Evidence: <quote / observation>
```

## Anti-patterns

- 把内部员工意见默认当成终端用户
- 无场景的功能愿望清单
- User 直接向 Developers 派工（应经 PO）
