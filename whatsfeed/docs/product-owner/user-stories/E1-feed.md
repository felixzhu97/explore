# E1 信息流

← [用户故事地图](../User-Story-Map.md)

## 背景

用户需要在 Web / 移动端浏览与互动内容。

---

## US-01 浏览信息流

**As a** Web 用户  
**I want** 打开首页看到个性化或时间序信息流  
**So that** 我可以快速发现关注对象与推荐内容

### 验收标准

1. **Scenario** 加载信息流
   **GIVEN** 用户已登录或允许访客浏览  
   **WHEN** 打开 Feed 页  
   **THEN** 展示帖子列表  
   **AND** 支持下拉刷新或分页

2. **Scenario** 打开单帖
   **GIVEN** 信息流中有帖子  
   **WHEN** 用户点击某条  
   **THEN** 进入详情并可见评论入口
