# E2 聊天

← [用户故事地图](../User-Story-Map.md)

## 背景

用户通过实时通道收发消息。

---

## US-02 即时消息

**As a** 移动端用户  
**I want** 与联系人实时收发消息  
**So that** 我可以保持沟通不断线

### 验收标准

1. **Scenario** 发送消息
   **GIVEN** 用户在某会话中  
   **WHEN** 发送文本消息  
   **THEN** 消息出现在会话中  
   **AND** 对端可经 WebSocket 收到

2. **Scenario** 离线后补偿
   **GIVEN** 用户短暂离线  
   **WHEN** 重新连接  
   **THEN** 可拉取未读或最近消息

### 状态

规划中
